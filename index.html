How I build AI systems

One request, end to end, through the AI-as-a-Service Layer I designed and built. Every stage below exists in code, and each rule is held in place by a test.

Permission before retrieval

Data a user may not see is never fetched, so there is nothing to scrub afterwards. The access filter lives inside the retrieval query itself.

Proven by test_another_programme_is_never_retrieved

Cite or refuse

The model writes sentences; tools compute the numbers. If an answer states a figure no tool produced, the whole answer is refused, not trimmed.

Proven by test_an_invented_number_is_refused_not_trimmed

Tested like software

A golden set of 16 cases runs in CI next to 75 unit tests. A lost citation or a lost refusal blocks the merge.

Proven by test_the_whole_golden_set_passes
